# Serviços Locais — Atividade 08

Protótipo do Stitch convertido em páginas HTML com Bootstrap 5.3.

## Como executar

1. Abra esta pasta no VS Code.
2. No terminal, execute `npm install`.
3. Abra `index.html` usando Live Server.

O Bootstrap é carregado pela pasta `node_modules`, sem CDN. Os estilos adicionais ficam em `assets/css/style.css`.

As páginas são demonstrativas: filtros, busca e favoritos não gravam alterações. Os corações mudam apenas de aparência ao clicar; menus e modais usam o JavaScript do Bootstrap.

Todas as sete páginas do protótipo estão presentes. A barra inferior permanece visível durante a rolagem.
